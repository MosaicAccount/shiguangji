## 1. 最终目标

**让知识之间可以互相走过去，把「笔记列表」变成「知识库」，同时为 AI 接入准备数据基础。**

## 2. 范围

笔记正文的互链语法与渲染、反向链接、失效链接降级；影视条目的横向关联。涉及笔记与影视模块。

## 4. 非目标

- 不做知识图谱可视化；
- 不做条目与笔记之外的链接类型（如标签互链、外部资源引用）；
- 不做 AI 对话、摘要或问答（AI 接入属独立方向，见 [pending.md](pending.md)）。

## 5. 验收标准

- [ ] 正文中 `[[标题]]` 在列表预览与详情页均渲染为可点击链接，跳转正确；
- [ ] 反向链接面板列出的引用来源准确，链接可跳转；
- [ ] 标题重名时的行为符合 D-14 的决策，且不产生指向错误笔记的链接；
- [ ] 不存在的目标不产生死链；
- [ ] 回归：Markdown 既有语法（标题、列表、代码块、图片、链接）渲染无回归。

## 6. 数据与兼容性

- 实现分档，本期二选一（见 D-15）：
  - **轻方案**：反向链接用 `content like` 扫描，零表结构变更；
  - **重方案**：新增 `sgj_note_link` 关系表，需一次性解析存量 `content` 回填。
- **约束**：`sgj_note.content` 必须保持为纯 Markdown，不得把元数据拼入正文——这是后续 AI 接入按段落切块向量化的前提，现在遵守零成本，以后返工成本高。
