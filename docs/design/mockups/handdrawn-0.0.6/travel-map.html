足迹地图 · 重设计提案

双层地图

默认看手绘路线图（真实坐标相对投影 + 编号图钉 + 虚线路径）；要精确位置时一键切到真实地图（照片图钉）。下面这页可以点：切月份、点叠针、点图钉、切模式。

现有足迹页 →
去过（编号 = 到访顺序） 叠针 = 附近 N 处 想去（不受月份筛选）

示意位置 · 非比例 —— 方位关系真实，距离不是；要看精确位置就点右上「真实地图」。

兜底：同坐标多次到访。放大镜里按 14× 重投影仍然重合（同一家店去了两次这种），就不硬摆图钉了，落成一张纸片小列表——名称、日期、照片数，点条目照样进详情抽屉。图钉是给「不同地方」的，同一个地方反复去，列表反而更诚实。

业务逻辑

全国手绘图（默认 · 全年） ├─ 点月份胶囊 ──→ 重画路径与图钉（投影框不动，地图不跳） ├─ 点编号图钉 ──→ 详情抽屉（与地点卡片同一交互） ├─ 点叠针 ──────→ 放大镜局部图（簇内按 14× 重投影） │ ├─ 点子图钉 → 详情抽屉 │ └─ 点空白处 → 复原全国图 ├─ 点「真实地图」→ 高德模式（照片图钉 + 路线，现有能力保留） │ └─ 点照片 → 详情抽屉；点「手绘示意」返回 └─ 点想去图钉 ──→ 详情抽屉（想去态，可「定个日子」）
环节规则
投影等距圆柱相对投影：把全部足迹的经纬度包围盒映射到纸面（国内外地点通吃），保持方位关系；页角常驻「示意位置 · 非比例」。投影框按全部足迹计算，月份筛选不改变它。
防重叠 · 位移图钉最小间距 52px；力导向互斥微位移，单针位移上限 26px——只「挪半步」，方位感不破坏。
防重叠 · 聚合位移后仍 <30px（同城多点）→ 合成叠针（三针叠放 + 数量角标），停在真实位置；不去伪造间隔。
放大镜点叠针 → 一枚更大的玻璃镜片压在那一坨上：原图一切不动，镜片不透明底盖住叠针，镜内是一张新的局部手绘小地图（视口 = 簇内点经纬度包围盒，留 32% 余量，窄轴拉伸撑满内接方形的范围视图），三点自然展开，标注实际跨度 km 与「非等比」；镜片悬浮在簇的斜上方（方向自适应、不出画布），镜沿到叠针之间画一条圆锥光路（宽头贴镜、窄头箍住叠针）标明展示对象；同坐标 → 纸片列表兜底；点镜外或 × 复原。
月份口径按 finishDate 归月；胶囊只列有足迹的月份并带数量（空月不出现）；默认「全年」；切换只重画路径与图钉。
路径选中范围内按日期升序串联成虚线路径；仅 1 个点不画线；想去不进路径。
想去虚线图钉常显，不受月份筛选影响；点开是想去态详情（可定日子）。
空态一个足迹都没有 → 手绘空态 +「＋ 添加想去」；坐标缺失的地点不上图，仍在卡片与时间线里。
真实地图现有高德模式原样保留：照片图钉 + 就近聚合 + 路线 + 点选详情；与手绘图共用同一个装裱框，一次明确的模式切换，不做逐点击跳转。
性能个人站量级（≤ 数百点），投影 / 松弛 / 聚合全在前端一次算完，无接口改动。

为什么点图钉不直接跳高德：点图钉时用户要的是信息（照片 / 日期 / 短评），不是地理核查；逐点击在「手账跨页」和「工具地图」两种心智模型间跳，连看五个地方就要跳五次。地理核查是低频需求，用一次显式切换满足——两种地图里「点图钉 / 点照片 = 开详情」保持同一个动作。
