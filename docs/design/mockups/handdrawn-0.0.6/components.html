设计语言 · 形制层

共享组件

Element Plus 的形制逐件换成手绘语言：表单控件换肤，弹窗 / 抽屉 / 日期 / 消息自绘（D-43）。默认封面与页面小结条也在这里定形。所有组件都只拼装 --hd-* 令牌，页面不各画一遍（FR-007-1）。

01按钮

主按钮整块涂墨，次级只描抖框；悬停时轻微抬起并转 0.6°。表格 / 卡片里的动作一律用小号，避免和标题抢。

02状态 · 标签 · 印章

想看 在看 看过 旅行 电影 独立笔记 已归档 已完成 待补 3

状态是手写的胶囊，完成态用橄榄；印章只给「归档 / 完成」这类一次性判定，不参与筛选。

计划日期是最常用的小浮层：只保留月份步进与日期格，不做时分秒；选中格红描边 + 米色底。

05评分

4 星

用五枚手写星，点一下就落墨；空星是浅灰。只读态（卡片 / 详情）不显示空星，避免一排灰点抢注意力。

08消息提示

已保存到草稿箱 · 2 分钟前 已标记看过 同步失败，草稿仍在本机

提示条是横着贴的一小片纸：成功用橄榄、失败用陶红，2.5 秒自动收走；文案说清「发生了什么、接下来怎么办」，不只写「成功 / 失败」。

12Element Plus 映射（D-43）

Element Plus做法在手绘语言里
el-input / el-textarea换肤抖线框 + 方格纸底纹；焦点换陶红线，不加光晕
el-select / el-date-picker换肤 + 自绘浮层触发器换肤，浮层用纸片 + 手写星期；不做时分秒
el-checkbox / el-radio / el-switch换肤对勾手绘化、滑钮做成纸片上的圆点
el-dialog / el-drawer自绘纸片 + 胶带 + 墨色薄雾；标题即动作
el-message / el-message-box自绘小纸片提示条；确认框与完成弹窗同一套壳
el-pagination / el-empty / skeleton换肤纸片按钮 / 手绘空态 / 纸色骨架
el-upload / el-image换肤虚线胶带框；图片默认贴纸阴影与轻微旋转

原则：能用 EP 变量换肤的不自绘（表单控件、分页），交互复杂的浮层才自绘；自绘件必须与 hd-* 令牌同一套纸色 / 线色 / 圆角，避免「亮色手绘、暗色 EP」的混搭。
