手绘 · 一个人的手账

前台视觉从「冷雾胶片」整体切换为手绘手账风格，色彩同时换成一套「暖忆」色板：米纸、暖白、墨褐、陶红、赭石、橄榄——回忆是暖的，页面也该是暖的。不是把样式刷匀，而是换一套设计语言：纸是静的，贴纸是全的；线是抖的，字是清楚的。本组图覆盖首页 / 影单 / 书单 / 足迹 / 笔记（列表 · 详情 · 编辑）/ 搜索 / 登录注册，以及共享组件的形制层。

设计评审中 · 尚未进入编码 2026-10-19 · 对应需求 docs/requirements/0.0.6-handdrawn.md

01方向

拾光记本来就是一本「一个人的手账」。手绘不是装饰，是内容本来的样子：照片贴进去、胶带粘住、字写在格子里、完成盖个章。页面只做三件事——把内容摆成纸，把状态写成字，把动作留在手边。

暖

页面底是奶油米，纸是暖白，阴影带一点咖啡色；陶红、赭石、橄榄都退掉饱和度，像旧相册与旧书封。暗色不是反相，是夜里点灯：暖炭底 + 纸色字。

手写

全站霞鹜文楷；线是抖的（SVG 位移滤镜只上边框与分隔线），字是清楚的（文字层不套滤镜）。状态与日期用批注的口气写。

克制

每屏一个主角；红色只给主动作与当前状态，橄榄给「完成 / 书」，赭石给「地点 / 评分」。其余保持墨色与纸色，不用第二套装饰语言。

03设计语言

暖忆 v3：暖而不黄。页面底从奶油米调回近中性的暖白灰 #F5F2EC，纸是暖白，墨是暖褐；陶红 / 赭石 / 橄榄全部压低饱和，旧玫瑰只做装饰。暗色是中性暖炭 #1B1B1C（纸 #242426、字 #ECEBE8），不再带棕黄罩层。明暗两套都按 WCAG AA 校准正文对比度，所有页面共用这一套令牌。

04本轮迭代：暖色、默认封面、小结条、足迹去双模式

这三处是这一轮根据反馈改的，改动都收在共享令牌与共享组件里，页面只拼装。

默认封面

没有上传图时不再用色块：模块网格用 A 影像封面（照片 + 标题压暗角），首页时间线 / 回顾小图用 C 手账拼贴（纸卡贴照片、不放字）。三个封面方向对照 →

沙丘 2 失明症漫记 洱海

页面小结条

影单 / 书单 / 足迹 / 笔记都在页头放同一行小结：这段时间攒下了什么、最近一次是什么。像手账页脚的一行铅笔字。

看过 87 部· 剧集 32 部· 在看 1 部 最近 沙丘 2

足迹：取消双模式

不再让用户在「卡片 / 地图」之间来回切：一页里地图看方位、时间线看年份、卡片看细节。点地图上的点可以定位到下面那张卡。

浏览与编辑都留在同一屏，少一次模式切换，也少一次「我刚才是哪个视图」。

06评审要点

先看两页

  • 影单 / 书单：手绘在「密度页」能不能扫读——封面、标题、评分、短评、动作是否还分得清；移动端双列是否还看得清。
  • 笔记详情：手绘在「长文」能不能读——行高、标题层级、引用与代码块、目录与反链是否安静；图片与票根是否像「贴进去的」而不是「放进去的」。

再看四件事

  • 暖色板：米纸 / 墨褐 / 陶红 / 赭石 / 橄榄是否够「回忆的温馨」，又不至于甜腻或发黄。
  • 默认封面：没有图时，票根 / 布封 / 老照片 / 纸页是否还像一件「作品」，而不是占位块。
  • 暗色：夜间是暖炭 + 纸色，不是反相；每页都有暗色图。
  • 移动端：390px 宽不横向溢出；底部 tab 四项不变。
  • 可读性：正文对比度 ≥ 4.5:1（大字号 ≥ 3:1），最小字号 13px；截图工具的 lint 已按此处理。

本组图不覆盖

  • 后台管理端（D-41 建议不纳入）；
  • 心愿页 /plan 与年度回顾 /review：已落地手绘皮肤，本版只并入全站令牌、视觉不变，不在本组图重画；
  • 草稿箱 /note/draft：沿用笔记列表语言，不出独立图；
  • 交互与动效（悬停、主题圆形扩散、加载态过渡）不在静态设计图范围，实现阶段按现有交互规范补。

07默认做法提示的处理

  • 标题上方眉标 / 英文大写小字：保留。手账扉页的日期眉标、票根上的印刷字是形制的一部分，不是「AI 味」标签；全部为装饰性小字，不承载关键信息。
  • 卡片里套卡片：仅组件谱的「展台」如此，是刻意的陈列层级（展品放在纸卡上）；业务页面不叠卡。
  • 彩色单侧边线：目录当前项的笔触与引用块的红侧笔，来自手写批注，不用于装饰卡片。
  • 对比度：亮 / 暗两套令牌都按 AA 校准；亮色次级墨 #665C50、三级墨 #756B5E，暗色对应 #B8B1A2 / #A9A295。
