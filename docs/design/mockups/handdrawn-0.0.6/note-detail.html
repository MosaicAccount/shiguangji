散场的时候，检票员把票根撕下一角递还给我。那张纸不厚，边缘已经起毛，却在口袋里一直留到今天。每次翻到它，我都能想起那天影院的空调、邻座拆糖纸的声音，以及沙虫第一次从沙丘里立起来时，低频从座位底下长出来的感觉。

票根会皱，也会掉出来

数字票根不会皱、不会褪色，但也不会在某个下午从书里掉出来。我并不是反对电子票——它更快、更准、更不会丢。只是「不会丢」和「值得留下」是两件事。

我留下了什么

一张票根能留下的东西比想象中多：

  • 那天——日期、场次、影厅，连晚饭吃了什么都跟着回来；
  • 那排座位——7 排 12 座，后来才发现是看 IMAX 最好的位置之一；
  • 那个人——票根的背面有一行字，是同行的人写的。

这些东西不会出现在任何一条观看记录里。记录告诉我「看过」，票根告诉我「怎么看的」。我把它们一起写进这篇笔记，再链到 克拉拉与太阳——那本书里也有一张被我夹在书页里的票根。

一个小习惯

现在每看完一部电影，我会把票根拍照、贴进手账，然后在正文里留一句当天最想记住的细节。不为了完整，只为了下次翻到的时候，能重新听见那个下午。
