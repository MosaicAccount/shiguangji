      本次原型覆盖
      
    
        
      
      1. 正文互链：详情页里的 [[番茄工作法]] 可点；[[深度工作]] 未找到、[[周记]] 标题重名，都显示为不可点的降级样式；代码块里的 [[不该成链]] 原样保留。
        2. 
      
      2. 反向链接：正文末尾列出「谁引用了本篇」，标题可点；时间管理与番茄工作法互相引用（环），两边的反链都成立。
        3. 
      
      3. 重名状态：顶部切换「标题重名」，可看反链区块改为说明、不列来源。
        4. 
      
      4. 插入互链：编辑器工具栏「插入笔记链接」→ 按标题搜索 → 选中后插入到光标处；同名笔记合并、含 [ ] 的标题置灰。
        5. 
      
      5. 改标题提醒：把标题改一个字再点保存，会提示有 2 篇笔记仍引用旧标题；取消则返回修改。
        6. 
      
      6. 全局搜索：影单 / 书单 / 足迹 / 笔记四组，空组隐藏、组头给总数；2 字门槛；笔记结果带「文中 N 处」。
        7. 
    
      
    
      原型边界：搜索里的条目点击只提示真实跳转地址（/movie?type=TV&itemId= 等）；不接后端、不实现图片上传；移动端编辑器预览按上下堆叠展示，真实产品里是弹窗。
