本屏标注

  1. 新增：导入 md 入口，只有列表页这一个（条目详情页不放；后台入口见 #58，阻塞于 #57）。全程在浏览器本地读取与解析，没有任何上传请求，解析完直接跳编辑页预填。按钮按 isLogin 显隐，真正的门是 /note/edit 的路由守卫。
  2. 新增：草稿入口条。仅登录且草稿数 > 0 时渲染；访客与失效 token 都不发这个请求（避免 401 弹「登录状态已过期」）。
  3. 改动：搜索框 placeholder 由「搜索笔记标题」改为「搜索标题与正文」；检索走 FULLTEXT + ngram，至少输入 2 个字（少于此长度给提示，不是静默空结果）。
  4. 改动：卡片摘要由「渲染整篇 Markdown」改为 纯文本摘要常显（无关键词取开头，有关键词以命中处为中心）；关键词高亮按字面量切片段渲染，不拼 HTML、不走 v-html。
  5. 改动：底部 32px 渐隐改为仅在内容真的溢出时出现——摘要是定长的（约 120 字），原来那套「预览整篇必然溢出」的前提已不成立，否则渐隐会压在完整文字上像被截断。
  6. 改动：移动端筛选栏的媒体查询选择器由失效的 .toolbar 改为 .filter-bar，搜索框恢复占满整行（此前从未生效）。
  7. 新增：导入的两道前置拦截——见「导入·草稿冲突」与「导入·超长拦截」两个状态。① 编辑页里已有一份未保存的空白草稿时先问一句：新增态编辑页与空白草稿是同一个槽位（note_id = 0），而初始化会 无条件 用草稿覆盖表单，不问就是一份内容静默消失（[设计 结论 42](../../note-0.0.2-design.md)）。② 超过 10 万字的文件在 导入时 就拦下、不进编辑页，否则用户会白编辑一遍才发现保存被拒（[设计 结论 34](../../note-0.0.2-design.md)）。

无徽标的改动：列表页不再 import MarkdownViewer（首屏不付高亮库体积），因此本页视觉与代码高亮无关；条目筛选提示沿用既有样式，无功能变化。
未在本屏建模：真实搜索请求、分页请求、删除确认弹窗（样式同本页的导入拦截弹窗）、文件选择器本身与解析失败提示。banner 与卡片视觉均为既有样式，未改动。
