「一个笔记命中多个关键词，循环播放，怎么播放？」issue #31 评审追问

  1. 先厘清：issue 里的「循环」是渲染手法，不是播放。原文指把摘要按关键词切成几段、模板里 v-for 渲染 span。按 issue 现状（下方方案 A）卡片不播：无论命中几个词，只有一段摘要、以第一个命中为中心，窗口内的命中全部高亮，窗口外的命中不可见。
  2. 若要多命中轮播（方案 B，本页重点）：命中按正文出现顺序成窗（相邻命中并入同窗，最多 3 窗），每 4 秒回环推进；悬停、按住、键盘焦点、滚出视口任一即暂停；点圆点接管后停播；系统开启「减弱动态效果」时不自动播。完整规则见右侧面板。
  3. 推荐：v1 按 issue 原样上单窗口；轮播作为独立增量，接口数据结构一次性按数组设计（excerpts[≤3] + hitTotal），v1 令其长度为 1。

播放规则（方案 B）

  • 推进：每 4 秒切下一窗，到尾回环（1→2→3→1）；窗口内所有命中词都高亮，不按关键词分色。
  • 错峰：同屏多卡依次延迟 1.2 秒启动，避免整页同翻。
  • 暂停：悬停 / 按住 / 键盘焦点进入 / 卡片滚出视口，任一即暂停，条件解除后从当前窗继续。
  • 接管：点圆点后该卡退出自动播放（重新搜索恢复）；点击卡片本体仍是打开详情，不做「点摘要切窗」。
  • 动效：新窗上滑淡入 200ms——列表本身纵向滚动，横向滑动易被误读为翻页手势。
  • 降级：系统「减弱动态效果」开启时不自动播，只留手动跳转（检测到时本页演示同样关闭自动播放）。

本屏标注

  1. 成窗：6 处命中 → 3 窗。相邻命中并入同窗、按正文出现顺序排列、最多 3 窗；两个关键词（草稿、摘要，多词检索是 OR 语义）的命中混排在同一条窗口队列里。
  2. 播放指示：「1/3 · 共 6 处命中」。圆点代表窗口数（不是命中数），活动圆点内的进度条即本轮剩余时间；圆点可 Tab 聚焦、可点击跳转。
  3. 高亮与定高：窗口内每次出现都高亮，多关键词同一样式（分色是噪音且色弱不友好）；切分按字面量 indexOf、不拼正则、不走 v-html（issue 验收项）。摘要区固定 3 行高，窗与窗切换不跳动；底部渐隐仅真溢出时出现。
  4. 标题命中：标题与正文都命中时，标题同样高亮，命中计数含标题。
  5. 只命中标题：摘要取正文开头、标题高亮——issue 既有规则，两方案相同。
  6. 单命中：静态展示，无播放元素——issue 既有形态，两方案相同。
  7. 视口与错峰：滚出视口即暂停（把这张卡滚出去再滚回来，时间上能看出它没在播）；同屏多卡错峰 1.2 秒启动。这张卡（2 处命中 → 2 窗）是混排关键词的最小例子。
  8. 切窗联动：色块即窗口，与「设计复盘」卡实时联动；点击色块跳到对应窗口（等同接管，该卡停播）。方案 A 下不轮播，此图描述的是方案 B 的切法。

推荐路径：v1 按 #31 原样上单窗口（切到顶部「A · 单窗口静态」即 issue 现状）；方案 B 作为独立增量按本页规格实施，excerpts 结构一次到位、v1 令长度为 1。
