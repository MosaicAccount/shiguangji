0.0.2 设计图 · 收口笔记

笔记从「能写」变成「写不丢、找得回」。本组图只覆盖本版新增与改动的界面，不是全站重设计。

怎么用

  • 每屏一页，页内用顶部工具条切换：状态（本版的各个分支）、深色模式、桌面 / 移动端、标注。
  • 橙色数字气泡与本页底部的「本屏标注」一一对应；关掉「标注」可看无打扰的真实观感。
  • 设备框是可滚动的真视口：顶栏与移动端底部标签栏会像真机一样吸住，可以据此判断遮挡与留白。
  • 视觉基线取自 shiguangji-web/src/assets/styles/front-tokens.scss（冷雾胶片 v3.3）；后台页沿用既有 admin 主题，不另创一套。

本组图是静态保真，不连接真实接口：表单可聚焦、开关可切换、弹窗可关闭，但保存 / 上传 / 检索均为示意。这些是刻意的边界，不是缺失。

出图口径

  • 覆盖：需求 §3.4 的界面清单 + 后台新增的两个动作。条目详情的关联笔记列表沿用列表页的摘要样式，不单独出图。
  • 每屏都有移动端（≤768px）与深色模式两个变体——页内切换，不另存文件。
  • 深色单独出的原因：代码块在两种主题下都保持深色（底色固定 #282c34），需要确认它在浅色页面里的对比是否协调。
  • 移动端单独出的原因：本版有三处只在移动端成立的差异——底部标签栏遮挡、关闭页面不承诺 beforeunload、编辑页预览走弹窗。
  • 本组图不含：Word / docx 相关界面（本版只做 md）、批量导入导出、前台下载入口（出口只在后台）、草稿的自动过期（不做）。
