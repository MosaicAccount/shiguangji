本屏标注

  1. 新增页：/note/draft，仅登录可进（不在免登录白名单）。入口只有笔记列表页的草稿入口条，前台导航不加项。
  2. 新增：配额提示（n / 20）。上限只统计新笔记草稿（note_id 为空）；编辑已有笔记产生的草稿不入箱、也不占额。
  3. 新增：标题为空时用正文首行兜底。取的是与列表摘要同一套剥离逻辑（去 Markdown 标记、去图片、去 front-matter），不另写一份。
  4. 新增：硬删除 + 确认弹窗。草稿不进回收站——避免出现第二个暂存区；删除后该行直接消失，配额立刻释放。
  5. 改动：相对时间（「3 分钟前」）走 formatTime()，但后端给的是 yyyy-MM-dd HH:mm:ss，必须先经解析函数转 epoch——直接喂进去会渲染成 NaN月NaN日。
  6. 改动：移动端底部自留 76px，不被固定标签栏遮挡（沿用 detail.vue 的 FAB 偏移做法）。
