本屏标注

  1. 新增：代码块语法高亮。新增 highlight.js + marked-highlight 两个依赖（marked 12 已移除内置 highlight 选项）。语言白名单用 highlight.js/lib/common（约 35 种常用语言），不引全量。
  2. 约束：只高亮显式标注且认识的语言，不启用自动猜语言（长块明显变慢且易猜错）。见「无标注 / 未知语言」状态。
  3. 约束：hljs 生成的 span.hljs-* 必须活过既有的 DOMPurify.sanitize 管道——class 默认在白名单内，但要写成 spec 断言，否则哪天被过滤掉只会表现为「高亮突然没了」。
  4. 约束：高亮 CSS 不能新开一段不带 :deep() 的 scoped 规则。本组件的样式全部写在 <style scoped> + :deep() 里；v-html 生成的节点没有 data-v 属性，普通 scoped 规则对它不生效——这是本版最容易踩的坑。
  5. 改动：主题用 highlight.js/styles/atom-one-dark.css，其底色与既有 pre 的固定 #282c34 同源，因此两种主题下代码块都保持深色、不随主题翻转。既有的 pre code 规则特异性更高，会覆盖主题对 code 的底色，无需改 pre 配色。
  6. 改动：本页与编辑页共用 MarkdownViewer，高亮自动同时生效；列表页不再引用该组件，所以高亮库不进首屏。右侧大纲为既有功能（#26），本次未改动。

未建模：真实的大纲锚点滚动与 scroll-spy、图片与相册、评论。
