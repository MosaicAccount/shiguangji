计划 · 三态与计划日期

四个内容模块（影单 / 书单 / 足迹 / 笔记）里，影单、书单、足迹原来只有「想看」和「看过」两端。本期补上中间态 DOING（在看 / 在读），让既有的「计划日期」字段在前台露出，并新增汇总页 /plan。地点不加中间态——只用「想去 + 计划日期」表达计划。

怎么用

  • 每屏一页，页内用顶部工具条切换：状态、深色模式、桌面 / 移动端、标注。
  • 橙色数字气泡与页脚「本屏标注」一一对应；关掉「标注」是无打扰观感。
  • 设备框是可滚动的真视口：/plan 的四组列表、地图下的时间线、完成弹窗里的表单都能滚，可以据此判断遮挡与留白。
  • 视觉基线取自 shiguangji-web/src/assets/styles/front-tokens.scss（冷雾胶片 v3.3）；弹窗、抽屉、胶囊都沿用 Element Plus 结构，但配色走 --sgj-*（前台主题下的 Element Plus）。

本组图是静态保真，不连接真实接口：按钮可点、弹窗可关、状态可切，但日期选择、评分、图片上传与跳转均为示意。这些是刻意的边界，不是缺失。

出图口径

  • 覆盖：FR-003-1 ~ FR-003-7 的用户可见部分。四屏的分工是——/plan 是新页（新增），三态胶囊与流转是把既有交互从两端扩到三端（改动），首页心愿单对齐与统一完成弹窗兼有改动与修复，足迹地图是 FR-003-6 的现状核实页，不产出改动。
  • 每屏都有移动端（≤768px）与深色模式两个变体——页内切换，不另存文件。移动端差异：/plan 单列、分组标题吸顶、卡片操作收成短文案；三态屏单列卡片；地图降为 420px 高。
  • 文案即定稿：四屏里的中文文案会与实现逐字对齐——尤其「逾期 3 天」「今天 / 明天 / 周五」「还没有计划 —— 去影单 / 书单挑一个，填上打算哪天看。」「心愿 · 在想 8 / 在做 4」「＋ 定个日子」。图里的说明性文字只出现在标注与页脚，不混进界面文案。
  • 既有口径不动：hero 统计数字仍只显示已完成（看过 / 读过 / 去过 / 笔记），本期不改；首页时间线仍只含 DONE；三个模块的「取消完成」文案与位置不变。
  • 图片占位：全部用 CSS 渐变圆角块 + 衬线字（影 / 剧 / 书 / 地）表示封面，不引用任何外部图片；地图底图是纯 CSS 画的示意底（浅灰网格 + 道路/水域色块），不是真实瓦片。
  • 本组图不含：后端字典 DDL 与 buildSummary 的三态分支修改（见需求 §7 风险提示）、提醒与通知、「集数 / 页数进度」（D-10 本期不做）、清单子项、is_public（D-21 不提前）。

唯一一条既知不一致：全部计划 → 在现有代码里误指向 /note。本组图按修复后的形态画 /plan，见 首页屏 标注。
