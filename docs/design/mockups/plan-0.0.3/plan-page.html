笔记

本屏标注

  1. 新增：页头一行给全四个数——月份、总数、在想、在做。「在想」= WANT 数，「在做」= DOING 数，两者相加等于总数（/plan 的集合就是 WANT + DOING，DONE 不进此页）。页面本身不再重复筛选控件：四组已经把「什么时候」分完了，再加一排状态胶囊会把两套分法混在一起。
  2. 新增：逾期用危险色 + 相对天数，而不是绝对日期。计划日期早于今天就是逾期，写「逾期 3 天」比 2026-10-11 更能回答「欠了多久」。绝对日期在悬停/详情里仍可查，本屏不铺开。
  3. 新增：本周是当前关注区。「今天 / 明天 / 周五」这类相对文案是本周组专用的读法，越靠近今天越具体；组头与计数胶囊换主色，让它在一屏里第一眼被看到。跨到「以后」组就退回绝对日期（2026-11-02）——远处的事情说「还有 23 天」没有意义。
  4. 新增：操作按钮按状态只给下一步。WANT 给「开始 →」（WANT → DOING），DOING 给「标记看过 / 读过」（DOING → DONE，走完成弹窗，见首页屏）。不并排给两个按钮：从「想看」直接跳到「看过」是既有的 标记看过 那条路，在各自的模块页里已经存在，计划页只承担「推进一格」。
  5. 新增：未排期组置底并自带解释。没有日期的条目不是二等公民，它缺的只是一个日期——所以组头直说「点『定个日子』补上」，每张卡片的右侧也是同一个动作。列排在这里，用户才知道自己的心愿没有丢。
  6. 新增：空态给两条出口而不是一句「暂无数据」。新用户第一次点进 /plan 必然是空的（还没有任何条目有日期），此时最该做的是去挑一个——所以两个入口按钮直达影单与书单。空态也有页头（四个数都是 0），页头恒在、只换主体，避免整页跳变成一句提示。
  7. 新增：加载中是骨架而不是转圈。/plan 一屏四组、每组数条，骨架能提前交代版式（封面块 + 标题 + 状态 + 按钮），加载完成时不跳版。骨架克制到两组，不做整屏假数据。

未建模：真实接口与分页（/plan 一次拉全量，量大时的分页或虚拟滚动未定）、拖动改期、组内手动排序、批量改期、提醒与通知（需求 §4 非目标）、完成弹窗本体（见 首页屏）。
既有不改：前台页头与移动底部 tab——移动端 tab 仍是四项（首页 / 影单 / 足迹 / 笔记），/plan 不进移动 tab，从首页心愿单卡片进入（D-7 建议：桌面导航加一项，移动端不动）。移动端差异：单列、组头吸顶（top 60px 让开页头）、卡片操作按钮换行到右下。本屏省略了前台页脚（滚动到底才可见，与四组列表无关）。
