本屏标注

  1. 新增：「在看」是本期新增的字典值（sgj_movie_status 加一行 DOING），但胶囊本身是 v-for 循环字典渲染的，所以模板结构不动——多一枚胶囊是数据变化，不是代码变化。这一屏把它画出来，是为了对齐三枚胶囊的视觉权重与位置：想看 / 在看 / 看过按字典 dict_sort 排，新的值插在中间，不挪到首尾。
  2. 新增：WANT 卡片给两个动作——主按钮「开始看 →」（WANT → DOING）与次按钮「标记看过」（WANT → DONE，走完成弹窗）。既有实现只给了后者（标记看过，直接跳到底）。补前者的理由是补记场景：一部剧要看一个月，「在看」得能表达出来，否则用户只能在两个错的状态里选。
  3. 新增：DOING 卡片给「标记看过」与「取消在看」。前进一格是完成（弹窗），后退一格是退回心愿；不在卡上直接给「取消看过」——从「在看」一步跳到「看过再取消」没有语义。
  4. 改动：DONE 卡片仍是「取消看过」一枚，位置与文案不变（既有行为，本期只做回归）。徽标与按钮的文案全部由类型参数化：影视 想看 / 在看 / 看过，书籍 想读 / 在读 / 已读，足迹 想去 / 去过。
  5. 新增：卡片右上角露出计划日期。有日期显示日期（2026-10-16），没有日期显示 ＋ 定个日子——后者是虚线描边的空心胶囊，与实心的日期胶囊在视觉上分得开。为什么放在封面右上角而不是正文里：封面左上是类型胶囊，正文第一行是标题/元信息，日期是「什么时候」的属性、不是「是什么」的属性，贴在封面上更符合阅读顺序，也不挤正文。
  6. 新增：书单同一形态——「在读」胶囊 + 开始读 → / 标记已读 / 取消在读。三态不是影视专有，书单是同一套状态机（sgj_book_status）；书比剧更常「在读」，这个中间态在书单上比在影单上更值钱。
  7. 新增：足迹页只有两枚胶囊，并额外露出一行「计划日期」。地点不引入 DOING 的理由写在页内提示里：「想去」本身就等于「还没去」，再造一个「在计划」与人话对不上；而计划该有的信息（哪天去）由日期承担，不需要状态值帮忙。这条是 D-5 的建议结论，图上按「地点两态 + 计划日期」画。
  8. 改动：书单的「开始读 →」与「标记已读」并排，与影单同构。注意字典值是三套（sgj_movie_status / sgj_book_status / sgj_place_status），但状态字面量是同一套（WANT / DOING / DONE）——实现上按状态值判断流转，按字典标签显示文案，不要按标签字符串比较。
  9. 新增：地点不做中间态，所以计划日期必须露出来——否则「想去 + 计划日期」这条表达在足迹页上根本没有入口。有日期的卡片在正文里显示 计划日期 2026-10-17（主色），没日期的显示虚线的 ＋ 定个日子。
  10. 新增：足迹卡片的两个动作：标记去过 + 改期。改期是本期新露出的字段带来的必然动作——给了日期就必须能改，否则「定个日子」是一次性的。
  11. 新增：无日期的「定个日子」入口在卡片操作区也有一个（泉州 · 西街）。封面上那个是「看一眼就知道没排期」，这里的按钮是「直接去排」——同一动作两处出现，不是重复，是让不同扫描路径都能落到动作上。
  12. 改动：抽屉徽标从中性的二值判断扩到显式三态。现状 item.status === 'DONE' ? doneLabel : wantLabel 会把 DOING 显示成「想看」，这是本期必须改的一处隐蔽错误（与需求 §7 列的 else 兜底同类）。三枚徽标的颜色：想看=灰铜、在看=灰陶、看过=鼠尾草。
  13. 新增：抽屉里写清可逆的流转。「在看」能退回「想看」、「看过」能退回「在看」，不是单向阶梯。抽屉是唯一能一眼看全三个位置的地方，所以把关系画在这里，卡片上只给「下一步」。
  14. 新增：只改 MediaDetailDrawer，不改足迹的 place-drawer。两个组件是分开的两份实现（类名前缀分别是 md- 与 d-），足迹抽屉只有 WANT / DONE 两个分支，本期不动它——只确认它的「计划日期」要跟着卡片一起露出（本屏画了这一处）。
  15. 新增：地点抽屉的两态徽标与计划日期行。这里是 FR-003-3（计划日期前台可见）在足迹侧的落点：字段在详情里可读、可改期。

未建模：真实接口与分页、状态筛选的服务端查询、标签筛选（本屏只画了静态标签行）、详情抽屉里的照片相册与笔记关联、地点地图选点。
既有不改：banner、搜索框、标签行、网格断点（影视 minmax(288px,1fr)、足迹 minmax(220px,1fr)）、加载更多与到底提示、卡片 hover 抬升。「取消读过」的确认框（Element Plus confirm）本屏未画，行为不变。
移动端差异：单列网格、搜索框占满整行、抽屉从底部弹起（高 78%、顶部圆角），见工具条「移动端」。本屏的抽屉是叠加在页面上的静态展示：工具条里「详情抽屉（影视）」与「详情抽屉（地点）」是两个独立状态，切到哪一档就看到哪个抽屉（这样不用先滚到页面里某个按钮上去点），✕ 或点遮罩可关，不是真实路由。静止状态与真实路由无关，仅为把两个组件放在一起对照。
