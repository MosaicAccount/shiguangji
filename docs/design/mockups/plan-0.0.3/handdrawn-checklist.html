本屏标注（评审要点）

  1. 手写字体三选一：工具条「字体」切换对比（龙藏 / 马善政 / 芝蔓行）。默认龙藏（钢笔感、可读性最好）。本设计图已把三套字体按本页用字子集化后内嵌（无 CDN 依赖）——这也是产品落地的自托管方式，子集体积见下。
  2. 一组一张纸：纸顶一段胶带、纸与行都带一点歪斜（真实的手写从不上下笔都齐）。
  3. 线是抖的，字是清楚的：边框 / 行分隔 / 按钮 / 圆圈套 SVG 位移滤镜产生手绘抖动，文字层不套滤镜保证可读。
  4. 方框 = 状态也是动作：空框 = 在想；涂鸦痕 = 在做（陶红笔迹）；悬停出现淡红勾提示「点我推进」。地点点框给引导提示。
  5. 日间 = 纸 + 钢笔，夜间 = 黑板 + 粉笔：工具条切主题。同一骨架换墨不换结构，粉笔白与三个品牌色（陶红 / 琥珀 / 鼠尾草）都换了更亮的墨。
  6. 按钮两级：推进动作（开始 / 标记）整块涂墨，像用马克笔划重点；其余（改日期 / 退回 / 定个日子）描边抖框。
  7. 分页脚：手写体计数 + 描边「加载更多 ↓」。
  8. 空态：手绘涂鸦（星星 / 波浪线）+ 引导按钮，不是冷冰冰的空白。
