索引回顾页入口与边界

回顾 · 回看一段时间的积累

写入路径已经完整（标签、封面、地图、照片、评分、短评），但回读侧只有一条按月分组的时间线。本期新增回顾页 /review：按年份把这一年的条目与笔记收成一张纸——有多少、去过哪、最好的是什么、都是些什么。零表结构变更，全部基于 finish_date、rating、tags、地点经纬度与笔记数量聚合。

怎么用

  • 每屏一页，页内用顶部工具条切换：状态（默认 / 空态 / 加载中）、场景与入口方案（仅入口屏）、深色模式、桌面 / 移动端、标注。
  • 橙色数字气泡与页脚「本屏标注」一一对应；关掉「标注」是无打扰观感。
  • 设备框是可滚动的真视口：回顾页的四个区块、入口屏的首页 hero 与时间线都能滚，可以据此判断遮挡与留白。
  • 视觉基线取自 shiguangji-web/src/assets/styles/front-tokens.scss（冷雾胶片 v3.3）；回顾页沿用首页 hero 的统计卡字形与「沉浸式分段标题 + 胶片齿孔」，让新页跟既有前台是同一个体系，而不是一套数据看板。

本组图是静态保真，不连接真实接口：年份可翻、状态可切、主题与视口可换，但地图、评分榜、标签的点击跳转均为示意。这些是刻意的边界，不是缺失。

出图口径

  • 覆盖：FR-004-1 ~ FR-004-5 的用户可见部分。两屏分工是——回顾页是本体（新增页面，三个区块 + 三种状态 + 足迹分档 + 两种弹层），入口屏是入口位置与隐私边界（FR-004-5 的两案对比 + D-11 的落点）。
  • 视觉：回顾页整体采用 0.0.6 的手绘皮肤（原冷雾版原型已作废并重建）。这一屏的 <link> 直接引产品在用的 shiguangji-web/src/views/front/plan/handdrawn.css 与自托管霞鹜文楷分片——令牌、纸张、胶带、抖线滤镜、类型配色全部照用，新增的只有报头布局、示意地图、骨架三处。页头 / 页脚 / 移动 tab 仍是冷雾（它们不属于本期改动），与今天的 /plan 一样是「手绘内容装在冷雾外壳里」。
  • 每屏都有桌面与移动端、亮色与暗色两组变体——页内切换，不另存文件。移动端差异：回顾页报头改单列（年份在上、说明句在下）、年份降到 54px、统计卡两列等宽、逐点阈值从 10 降到 5、图上只留编号而名字进图下清单、评分两栏改单列、标签改单列；入口屏 hero 单列、入口卡与 CTA 按既有 flex-wrap 换行、移动端 tab 仍是四项。
  • 文案即定稿：两屏里的中文文案会与实现逐字对齐——尤其「这一年，你记录了 87 件值得记住的小事。」「条目按完成日期归年 · 笔记按写下时间归年」「按去过的先后串起来，不是路线图 —— 两点之间没有画『怎么走』」「只有打过分的条目参与评选」「2021 年还没有记录」「回顾是你自己的页面」。图里的说明性文字只出现在标注、口径表与页脚，不混进界面文案。
  • 既有口径不动：首页 hero 统计数字仍只显示已完成，时间线仍只含 DONE，导航仍是 6 项（回顾不占导航位），移动端 tab 仍是四项。本组图不触碰任何既有页面的行为。
  • 图片与地图占位：封面用手绘圈 + 衬线字（影 / 剧 / 书）表示，不引用任何外部图片。足迹在回顾页里可切四种点数档：逐点档（手绘示意底 + 真实坐标落点 + 按先后连虚线）与聚合档（按省，压不到上限就自动降到大区）。
  • 本组图不含：后端聚合接口的形状与 SQL、年份参数校验与非法年份处理、高德瓦片与 SDK 懒加载、Top 榜与标签的点击跳转、导出成长图 / 海报（§4 非目标）、跨年对比与连续记录天数（D-13 不做）、自定义时间段（D-12 不做）、后台管理端任何改动、0.0.6 其余页面的换装。

一处已知的产品观察：前台目前没有独立登录页，守卫把访客送去的是后台登录页 /login，与前台视觉不同源。本组图把拦截结果画成提示卡（示意），该议题本期不解决，见入口屏标注 5。

口径与状态对照

区块数据来源归因口径参与条件空态
年度汇总
FR-004-1		 sgj_item + sgj_note 条目按 finish_date 归年；笔记按 create_time 归年。两类时间轴不同，不混用 status='DONE' + del_flag='0'；finish_date 为空的 DONE 条目不计入任何年度 页头保留、四个数归零；主体换成空态面板
足迹
FR-004-2 · 已定 B（地图）		 sgj_item（次序按 finish_date）+ sgj_item_place 的 latitude / longitude、province、country 同上年份口径（按完成日期归年），连线的先后也按完成日期 该年度 DONE 的地点。≤ 10（手机 ≤ 5）逐点画，没坐标的不上图但必须交代；更多则按省聚合，压不到 12 个泡就降到大区（境外按国家成泡） 随主体一起隐藏（空态面板取代）
评分 Top
FR-004-3		 sgj_item.rating（decimal(3,1)，0-10） 同上 rating 非空才参与；影视与书籍分两榜，地点不设榜；N 值与同分次级排序留待详细设计（建议 N=5~10，同分按完成日期近者在前） 该榜显示空
标签分布
FR-004-4		 sgj_item.tags（varchar(500)，英文逗号分隔） 同上 只统计该年度条目的标签；笔记标签不并入（笔记只贡献「写过」那个数）；需处理空串与标签内空格 随主体一起隐藏（空态面板取代）
可见性
D-11 · 全部区块		 — 仅登录可见：路由守卫弹登录、接口不标 @Anonymous（匿名 401）、访客不渲染入口。聚合范围经 AppScopeHelper.resolveCreateBy() 解析，不另写过滤；每个登录用户各自回看自己的年度 访客被守卫拦下
