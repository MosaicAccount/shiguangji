本屏标注

  1. 已拍板：回顾模块直接做成手绘（0.0.6 的皮肤先在这一页灰度）。这不是另起一套语言：本屏 <link> 引的就是产品在用的 shiguangji-web/src/views/front/plan/handdrawn.css（设计图与产品同源，仓库里有测试守着这条约束），字体是自托管霞鹜文楷分片；令牌、纸张、胶带、抖线滤镜、类型配色全部照用。页头 / 页脚 / 移动 tab 仍是冷雾——这与今天的 /plan 一模一样（手绘内容装在冷雾外壳里），也说明本页的灰度是干净的一步。本项讲整页，不另挂气泡。
  2. 新增：报头：年份在左、说明句在右，两者共用一条基线。年份 76px 是页面最大的一个字，说明句是它的题注；四个统计卡（影 / 书 / 地 / 文）拉成整行，卡片等高等宽。年份与说明句按基线对齐而不是按几何中心——数字几乎没有下伸部，几何居中会把说明句吊在年份的腰上，看着就是没对齐。统计卡的类型色用 hdk- 前缀（曾与正文注记 .hd-note 撞名，见本屏第 6 条以外的实现注意）。
  3. 新增：年份是可翻的，不是筛出来的。‹ › 步进任意年份（含没有记录的年份，翻到那里就是空态）；胶囊只列有记录的年份，从数据推导而不是写死 2020~2030。
  4. 新增：归因口径写在页面上（「条目按完成日期归年 · 笔记按写下时间归年」）。这不是内部实现细节：2023 年加进「想看」、2024 年才看完的片子属于 2024；不写清楚，用户看到数字会以为算错了。
  5. 已拍板：足迹只做 B（地图），A（横向串联）撤掉；B 分两档密度，聚合的粒度自适应。点数 ≤ 10（手机 ≤ 5）逐点画、按完成日期的先后连成虚线，更多则聚合——阈值随屏幕变不是洁癖：390px 里放 10 个图钉必然互相压。聚合从「省」开始试，压不到 12 个泡就降一级到「大区」（境外地点在省一级按国家成泡，到大区并成「境外」）；两级必然够用（大区一共 8 个），不需要第三级。为什么必须自适应：现有测试数据 15 个地点横跨 13 个省级行政区 + 2 个国家，按省是 15 个泡、超过上限，等于没聚合 —— 顶部「散 15」这一档就是它，会自动降到大区 8 个泡并在图下写明用了哪一级。虚线是时间顺序，不是行程轨迹，所以页面明写「不是路线图」。
  6. 新增：逐点档怎么不叠（用「点少 7 / 中 16」试）：按真实经纬度等比落位（x=经度 / y=-纬度，不做拉伸，境外与南半球也放得进框）、自动缩放到这一年的范围、按屏幕距离并簇（5%，约桌面 40px / 手机 20px，比 46px 的圈小，所以圈不叠）、标签上下换边、窄屏把名字移出地图进下方图例。聚合档的气泡位置是示意的（真实现里由高德定位），逐点档的位置是真坐标的 —— 这一点页面用图下那句「手绘示意 · 非比例」区分。
  7. 已拍板：B 的底是「手绘示意 + 按需开高德」，把手绘页从地图精度里解放出来。原来那个假陆块（变形虫）之所以难看，是因为它既是手绘又假装准确：既画不出真实形状，又不给真坐标。现在责任分家——示意底只管观感与顺序（手账点阵纸 + 指北针 + 点 + 虚线，页面明写「手绘示意 · 非比例地图」），精确位置在点开时才交给高德。这样回顾页不依赖第三方瓦片（0.0.6「整页手绘」不破口子）、首屏不加载高德 JS（只在真的想看某个点时才付这个代价）。连线压字也一并修了：标签加纸色光晕（box-shadow: 0 0 0 5px var(--hd-paper)），虚线经过标签时被干净地让开。
  8. 待定：「点开」的形态与容器。内容已定两套（用顶部「弹层关 / 点详情 / 省地图」看）：点详情是一张手绘卡片——胶带照片位 + 地名 + 日期与评分 + 短评 + 标签 + 「在地图上定位 / 看这条记录」，弹性展开（@keyframes hdspring）；组地图是手绘裱框里放高德瓦片、这一组去过的地方按真实坐标落图钉（近点并簇），点图钉再下钻到点详情 —— 这条「组 → 图钉 → 详情」的动线两种档位共用，组可以是省、大区或境外。容器我倾向「页内弹层 + 首次打开才懒加载高德」：体验连贯、首屏不受影响，代价是要引入高德 JS API。另一条路是跳足迹页并定位（如 /travel?focus={id}）：零新增依赖，但离开回顾页、且要 /travel 支持参数。这条请拍板。
  9. 新增：评分榜分影视 / 书籍两栏。一集剧和一本 400 页的书放同一张榜没有可比性，所以量纲分开；地点不设榜。只有打过分的条目参与，参与条数写在栏头（51 条里 32 条有评分）——不交代的话，用户会问「我看过的怎么没上」。同分时的次级排序与 N 的取值留待详细设计。
  10. 新增：标签按出现次数排序，长尾收成一行。手绘条形按最大计数归一，数字右对齐。Top 10 之外收成「其余 14 个标签各出现 1 次」——不折叠的话，51 条记录的标签会把这一屏变成一片噪音。标签只统计条目，笔记只贡献「写过」那个数。
  11. 新增：空态与加载中都是手绘的。空态：页头保留、四个数归零（与首页 hero「页头恒在、只换主体」一致，避免整页跳变），主体是一张纸上的便条加两处去处；并说明「胶囊只列有记录的年份」，否则用户会以为胶囊坏了。加载中：手绘骨架（歪盒子轮廓 + 浅纸底）而不是转圈或真站的灰色骨架，加载完成不跳版。
  12. 一句实话：地图这一块，原型即终稿；第三方依赖只留在「点开」那一步。示意底是纯 CSS/SVG（点阵纸、手绘圈、虚线），不联网、不要瓦片，画成什么样实现就是什么样；高德只在用户主动点开时才出场（按上面的容器方案）。代价是坐标成为硬依赖，而且没填坐标的地点必须交代清楚——本屏的做法是不落图、但在图里写一句、分组清单里也留着它（沙溪就是这么处理的）。本屏只给部分地点填了坐标，没填的那些点进分组会看到「只列名字」的状态，那本身也是要建模的一态。
  13. 一句实话：地图这一块，原型即终稿；第三方依赖只留在「点开」那一步。示意底是纯 CSS/SVG（点阵纸、手绘圈、虚线），不联网、不要瓦片，画成什么样实现就是什么样；高德只在用户主动点开时才出场（按上面的容器方案）。代价是坐标成为硬依赖，而且「没填坐标的地点」必须在图上交代清楚——本屏给的做法是不落图、但在框里写一句（沙溪就是这么处理的）。

未建模：真实接口与年份列表的下发（?year= 校验、非法年份处理）、高德那四件事（瓦片 / 缩放 / 标签避让 / 聚合）—— 都由它负责，本屏只画位置示意、Top 榜与标签的点击跳转、导出成长图 / 海报（§4 非目标）、跨年对比与连续记录天数（D-13 不做）、自定义时间段（D-12 不做）、弹层的真实跳转与高德 SDK 的懒加载（本屏用顶部 seg 直接切出两种内容）。
既有不改：页头导航仍是 6 项（回顾不占导航位，从首页 hero 进入，见 入口与边界屏）、移动 tab 仍是四项、页脚与主题切换不动。
