本屏标注

  1. 新增：年份是可翻的，不是筛出来的。‹ › 箭头步进任意年份（包括没有记录的年份，翻到那里就是空态）；下方胶囊只列有记录的年份，从数据推导而不是写死 2020~2030。翻页用箭头、跳转用胶囊，两种动作分工清楚。
  2. 新增：年份是 hero 的主角（74px 衬线数字），因为回顾的阅读单位就是一年。归因口径直接写在页面上——「条目按完成日期归年 · 笔记按写下时间归年」。这不是内部实现细节：2023 年加进「想看」、2024 年才看完的片子属于 2024；不写清楚，用户看到数字会以为算错了。
  3. 沿用：四个数沿用首页 hero 的同一套字形（封面占位衬线字 + 40px 圆角底 + 衬线大数字），只有统计范围不同：首页是「到现在为止」，这里是「这一年」。2×216px 网格与卡片尺寸照搬，hero 的体量也与首页一致。电影 / 剧集的拆分放进标签行（「看过 · 电影 24 · 剧集 12」），不再多开一张卡。
  4. 新增：地图只放这一年去过的点，与 /travel 的全量地图分工不同：那里回答「一共走过哪」，这里回答「这一年走过哪」。没坐标的地点不上图，但要交代——「沙溪」在下面的地点列表里以虚线胶囊出现并标「没填坐标」，而不是静默丢掉；这也是需求 §3.2 FR-004-2 点名的边界情况。底图是纯 CSS 示意底（网格 + 陆地 / 水域色块 + 道路），实际实现用既有 TravelMap。
  5. 新增：评分榜分影视 / 书籍两栏。一集剧和一本 400 页的书放同一张榜没有可比性，所以量纲分开；地点不设榜（rating 虽在主表，地点评分不参与）。只有打过分的条目参与，参与条数写在栏下（51 条里 32 条有评分）——不交代的话，用户会问「我看过的怎么没上」。同分时的次级排序（建议完成日期近者在前）与 N 的取值（建议 5~10）留待详细设计。
  6. 新增：标签按出现次数排序，长尾收成一行。条形长度按最大计数归一（12 为满格），数字右对齐并用等宽数字。Top 10 之外收成「其余 14 个标签各出现 1 次 + 展开全部」——不折叠的话，51 条记录的标签会把这一屏变成一片噪音。
  7. 新增：空态不写「暂无数据」。换到没有记录的年份时，页头保留但四个数归零（与首页 hero「页头恒在、只换主体」的逻辑一致，避免整页跳变），主体给一句解释（你从哪翻过来的）+ 两个去处（影单 / 书单）。空态也说明「胶囊只列有记录的年份」，否则用户会以为胶囊坏了。

未建模：真实接口与年份列表的下发（?year= 的校验、非法年份的处理）、地图真实瓦片与图钉交互（点击进地点详情）、Top 榜点击跳转条目、标签点击筛选、导出成长图 / 海报（需求 §4 非目标）、跨年对比与连续记录天数（D-13 已拍板不做）、自定义时间段（D-12 已拍板不做）。
既有不改：前台页头导航仍是 6 项（首页 / 影单 / 书单 / 足迹 / 笔记 / 心愿），回顾不占导航位，从首页 hero 进入——入口方案与隐私边界见 入口与边界屏。移动端底部 tab 仍是四项，不动。本屏省略了首页与各模块页，只画回顾页本体。
移动端差异：hero 单列、年份降到 50px、统计卡两列等宽（不再固定 216px）、地图 240px 高、Top 两栏改单列（影视在上、书籍在下）、标签改单列、英文小标题 sec-sub 隐藏。
