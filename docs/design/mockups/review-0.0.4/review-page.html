本屏标注

  1. 已拍板：回顾模块直接做成手绘（0.0.7 的皮肤先在这一页灰度）。这不是另起一套语言：本屏 <link> 引的就是产品在用的 shiguangji-web/src/views/front/plan/handdrawn.css（设计图与产品同源，仓库里有测试守着这条约束），字体是自托管霞鹜文楷分片；令牌、纸张、胶带、抖线滤镜、类型配色全部照用，新增的只有「报头布局」「路线」「骨架」三处。页头 / 页脚 / 移动 tab 仍是冷雾——这与今天的 /plan 一模一样（手绘内容装在冷雾外壳里），也说明本页的灰度是干净的一步。
  2. 新增：报头改成「年份在左、说明句在右」。原来年份一行、说明句另起一行，年份右边的六七百像素全是空的；现在把年度汇总那句话和归因口径挪到年份右侧（左对齐、与年份垂直居中），四个统计卡拉成整行——空位交给真信息，不撒装饰。年份仍是页面最大的一个字（76px），说明句是它的题注。
  3. 新增：归因口径写在页面上（「条目按完成日期归年 · 笔记按写下时间归年」）。这不是内部实现细节：2023 年加进「想看」、2024 年才看完的片子属于 2024；不写清楚，用户看到数字会以为算错了。
  4. 待定：足迹两案可切（A 串联 / B 地图）。两案取舍是「顺序准 vs 位置准」，不是好看难看：A 按 finish_date 的先后把地点串成一串，不依赖坐标（沙溪没填经纬度也照常是第 7 个点，需求里「无坐标地点不导致渲染异常」那条边界直接消失），代价是丢掉地理感；B 用手绘底图 + 虚线路线保住地理感，代价是坐标成为硬依赖、且底图只能是示意。虚线是时间顺序，不是行程轨迹——所以页面明写「不是路线图」，否则是产品在撒谎。
  5. 新增：评分榜分影视 / 书籍两栏。一集剧和一本 400 页的书放同一张榜没有可比性，所以量纲分开；地点不设榜。只有打过分的条目参与，参与条数写在栏头（51 条里 32 条有评分）——不交代的话，用户会问「我看过的怎么没上」。同分时的次级排序与 N 的取值留待详细设计。
  6. 新增：标签按出现次数排序，长尾收成一行。手绘条形按最大计数归一，数字右对齐。Top 10 之外收成「其余 14 个标签各出现 1 次」——不折叠的话，51 条记录的标签会把这一屏变成一片噪音。标签只统计条目，笔记只贡献「写过」那个数。
  7. 新增：空态与加载中都是手绘的。空态：页头保留、四个数归零（与首页 hero「页头恒在、只换主体」一致，避免整页跳变），主体是一张纸上的便条加两处去处；并说明「胶囊只列有记录的年份」，否则用户会以为胶囊坏了。加载中：手绘骨架（歪盒子轮廓 + 浅纸底）而不是转圈或真站的灰色骨架，加载完成不跳版。
  8. 发现：共享皮肤有一处缺口——书籍 / 地点的手绘圈是看不见的。handdrawn.css 只给影视写了 .g-movie .ring ellipse{stroke:…}，而 .g-book / .g-place 只设了字色、没设圈色，椭圆的 fill="none" 又让默认填充失效，于是这两类的圈根本不画。/plan 页里同理，只是恰好没暴露。本屏用一条 .hd-page .row .glyph .ring ellipse{stroke:currentColor} 统一成类型色，0.0.7 收敛皮肤时应并回 handdrawn.css。
