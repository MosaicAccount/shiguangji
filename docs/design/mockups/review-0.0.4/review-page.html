本屏标注

  1. 已拍板：回顾模块直接做成手绘（0.0.7 的皮肤先在这一页灰度）。这不是另起一套语言：本屏 <link> 引的就是产品在用的 shiguangji-web/src/views/front/plan/handdrawn.css（设计图与产品同源，仓库里有测试守着这条约束），字体是自托管霞鹜文楷分片；令牌、纸张、胶带、抖线滤镜、类型配色全部照用。页头 / 页脚 / 移动 tab 仍是冷雾——这与今天的 /plan 一模一样（手绘内容装在冷雾外壳里），也说明本页的灰度是干净的一步。本项讲整页，不另挂气泡。
  2. 新增：报头：年份在左、说明句在右，两者共用一条基线。年份 76px 是页面最大的一个字，说明句是它的题注；四个统计卡（影 / 书 / 地 / 文）拉成整行，卡片等高等宽。年份与说明句按基线对齐而不是按几何中心——数字几乎没有下伸部，几何居中会把说明句吊在年份的腰上，看着就是没对齐。统计卡的类型色用 hdk- 前缀（曾与正文注记 .hd-note 撞名，见本屏第 6 条以外的实现注意）。
  3. 新增：年份是可翻的，不是筛出来的。‹ › 步进任意年份（含没有记录的年份，翻到那里就是空态）；胶囊只列有记录的年份，从数据推导而不是写死 2020~2030。
  4. 新增：归因口径写在页面上（「条目按完成日期归年 · 笔记按写下时间归年」）。这不是内部实现细节：2023 年加进「想看」、2024 年才看完的片子属于 2024；不写清楚，用户看到数字会以为算错了。
  5. 待定：足迹两案可切（A 串联 / B 地图）。两案取舍是「顺序准 vs 位置准」，不是好看难看：A 按 finish_date 的先后把地点串成一串，不依赖坐标（沙溪没填经纬度也照常出现，需求里「无坐标地点不导致渲染异常」那条边界直接消失），代价是丢掉地理感；B 用手绘示意底保住「去过哪一片」的地理感，精确位置按需开高德（点任一点），代价是坐标成为硬依赖。虚线是时间顺序，不是行程轨迹——所以页面明写「不是路线图」，否则是产品在撒谎。
  6. 新增：足迹点变多了怎么办——两案各有一条规则（用顶部「点少 7 / 中 16 / 多 30」三个量级试）。A：站点 = 有出行的月份，不是地点，所以一年最多 12 站，版式永远不溢出（原来的 7 列网格与写死的虚线路径在点数上是硬伤）。站上写什么按能否容纳决定：站点 ≤ 8 写地名（同月并列，放不下收成「首个 +n」）；站点 > 8 只写月份 + 地点数，地名下移到清单。清单只在「链上写不全所有地名」时出现，按月列出、一个不少。B：底不承担地理精度，所以只需两档密度——点少时逐点标注（真实经纬度粗落位、自动缩放到这一年的范围、按屏幕距离并簇、标签上下换边），点多时按省计数。按省聚合也不是万灵药：现有测试数据里 11 个地点就横跨 11 个省级行政区 + 2 个国家，分散型数据聚合后一个省一个点，等于没聚合。
  7. 本次新增：B 改成「手绘示意底 + 按需开高德」，把手绘页从地图精度里解放出来。原来那个假陆块（变形虫）之所以难看，是因为它既是手绘又假装准确：既画不出真实形状，又不给真坐标。现在责任分家——示意底只管观感与顺序（手账点阵纸 + 指北针 + 点 + 虚线，页面明写「手绘示意 · 非比例地图」），精确位置在点开时才交给高德。这样回顾页不依赖第三方瓦片（0.0.7「整页手绘」不破口子）、首屏不加载高德 JS（只在真的想看某个点时才付这个代价），而 D-45 对足迹页「真地图裱框」的定案也不受影响（那是足迹页，不是回顾页）。
  8. 待定：「点开看真实位置」用哪种形态，两条路成本不同：(a) 页内弹窗/抽屉里嵌一张单点高德 —— 体验连贯，但回顾页要加载高德 JS API（体积与网络依赖）；(b) 跳去足迹页并定位该点（如 /travel?focus={id}）—— 零新增依赖、复用已有的真地图，代价是离开回顾页，且 /travel 需支持 focus 参数。本原型只画了入口提示，没建模跳转后的样子。
  9. 一句实话：两案的原型可信度现在对等了。改完之后 B 也是纯 CSS/SVG（点阵纸、手绘圈、虚线），不联网、不依赖瓦片，原型画成什么样、实现就是什么样——唯一的第三方依赖挪到了「点开」那一步，而它只在用户主动点的时候发生。剩下真正要选的，还是那个产品问题：回顾这一页要讲「顺序」还是「位置」。
  10. 新增：评分榜分影视 / 书籍两栏。一集剧和一本 400 页的书放同一张榜没有可比性，所以量纲分开；地点不设榜。只有打过分的条目参与，参与条数写在栏头（51 条里 32 条有评分）——不交代的话，用户会问「我看过的怎么没上」。同分时的次级排序与 N 的取值留待详细设计。
  11. 新增：标签按出现次数排序，长尾收成一行。手绘条形按最大计数归一，数字右对齐。Top 10 之外收成「其余 14 个标签各出现 1 次」——不折叠的话，51 条记录的标签会把这一屏变成一片噪音。标签只统计条目，笔记只贡献「写过」那个数。
  12. 新增：空态与加载中都是手绘的。空态：页头保留、四个数归零（与首页 hero「页头恒在、只换主体」一致，避免整页跳变），主体是一张纸上的便条加两处去处；并说明「胶囊只列有记录的年份」，否则用户会以为胶囊坏了。加载中：手绘骨架（歪盒子轮廓 + 浅纸底）而不是转圈或真站的灰色骨架，加载完成不跳版。
  13. 发现：共享皮肤有一处缺口——书籍 / 地点的手绘圈是看不见的。handdrawn.css 只给影视写了 .g-movie .ring ellipse{stroke:…}，而 .g-book / .g-place 只设了字色、没设圈色，椭圆的 fill="none" 又让默认填充失效，于是这两类的圈根本不画。/plan 页里同理，只是恰好没暴露。本屏用一条 .hd-page .row .glyph .ring ellipse{stroke:currentColor} 统一成类型色，0.0.7 收敛皮肤时应并回 handdrawn.css。

未建模：真实接口与年份列表的下发（?year= 校验、非法年份处理）、真地图的四件事（瓦片 / 缩放 / 标签避让 / 聚合）—— 都由高德负责，本屏只是位置示意、Top 榜与标签的点击跳转、导出成长图 / 海报（§4 非目标）、跨年对比与连续记录天数（D-13 不做）、自定义时间段（D-12 不做）、同一月份内地点超过 6 个时清单的折叠（本屏最多 3 个/月）。
