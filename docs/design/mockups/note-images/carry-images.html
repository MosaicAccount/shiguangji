本屏标注

  1. 新增：搬运弹窗的默认态。承接 FR-002-8 边界 3——相对路径 ![](./img/a.png) 与 Obsidian 的 ![[shot 2.png]] 指向的文件系统拿不到，必须由用户指出位置。计数分两档：12 处引用是正文里出现的次数（同一张图引用两次算两处），9 个文件是去重后真正要上传的数量——只报一个数会让「已搬运 9 张」和「12 处引用」对不上账。
  2. 新增：两种指认方式的分工。「选择图片文件夹」最准：能拿到 webkitRelativePath，./img/a.png 这类相对路径可以直接对上；「选择图片文件」只有文件名，按名字匹配——同名不同目录时可能配错，所以文案里明说「最准」而不是「推荐」。两者都不阻断流程，找不到的保留原引用。
  3. 新增：未命中清单逐条列出并保留原引用。列表用等宽字体原样回显引用串（含 ./ 与 ![[ ]] 两种写法），让用户能对着去本地找。只报「3 处没找到」而不给名字，用户没有任何可执行的下一步。超过三条时折叠为「等 3 处」。
  4. 新增：「跳过，只导入文字」始终可见，是纯文字按钮而不是第三个实底按钮——搬运是可选补救，不该和「继续」抢视觉权重，也不该被藏进右上角关闭图标里（那样用户以为整篇导入被取消了）。跳过后的后果见状态 6 的列表页提示。
  5. 新增：上限与忽略提示。超 10MB 的单文件、以及一次超过 50 张的部分被跳过，但已经搬上去的不回滚——所以提示是「已忽略」而不是「失败」，并说明上限值，用户才知道要分批。被忽略的文件在结果态一并显示（本屏状态 5 展示了它与结果态共存的样子）。
  6. 新增：跳过后的列表页 warning。弹窗关掉后不能就这么算了：正文里的引用还在，图就是显示不出来。提示常驻在列表页顶部，与既有 admin/前台 alert 样式同族（warning 色 #FDF6EC / #B88230），内容含处数与后果，可关闭。这与 0.0.2 里「本版不搬图片」的旧提示是同一处的改写——旧文案说明「本版不搬」，新文案说明「这次没搬，点进来可以补」。
  7. 新增：外链图片只说明、不搬运。http(s): / // 开头的是绝对地址，导入后浏览器直接去对方服务器取图，本来就能显示，没有可搬的东西——所以它不出现在「12 处本地引用」里。但必须说一句，否则 7 本地 + 3 外链的笔记只报「已搬运 7 张」，用户会以为另 3 张失败了。真要救防盗链 / 对方删图 / http 混合内容，得把外链下载到自己服务器（转存），那要服务器替用户访问任意网址，属另一主题（设计 结论 62 / 需求 D-31，另立 #68）。

未建模：真实的文件夹 / 文件选择器、上传接口与进度推送、同名文件的匹配算法（按 basename 还是含相对路径后缀优先）、去重与孤儿文件对账、data: base64 内嵌图（明确不处理）。
既有不改：列表页 banner、卡片、筛选栏、导入 md 入口、0.0.2 的三个导入拦截弹窗，视觉与行为都不变；本屏只新增搬运弹窗与顶部 warning。移动端差异：弹窗近满宽、按钮竖排（见工具条「移动端」）。
