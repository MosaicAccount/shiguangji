# 手绘（0.0.6）—— 详细设计

> 视觉唯一事实源：`docs/design/mockups/handdrawn-0.0.6/` 下 13 张设计图（亮 / 暗 / 移动三态齐全，截图存于同目录 `_shots/`）。
> **实现约束：样式一律复用 `handdrawn-site.css` 的共享类与 `--hd-*` 令牌，页面不得自造色值或第二套形制；落地后须与对应设计图截图比对，不一致算未完成。**

## 0. 共享层（先行）

- `handdrawn-site.css` 全量并入产品（令牌 / 外壳 / 纸片 / 按钮 / 表单 / 浮层 / 长文 / `.hd-summary` / `.hd-fallback`）。
- 前台导航外壳换装：暖白灰底 + 墨褐字 + 手绘下划线当前项；移动底部 tab 四项不变。
- EP 组件按架构 §4 映射换肤 / 自绘；组件谱见 `components.html`。

## 1. 首页（`home.html`）

hero 纸卡（眉标 / 问候 / 两个入口卡 / 日期便签）→ 统计四卡 + 心愿便签条 → 「我的时光」时间线（C 拼贴小图 + 卡片）→ 侧栏（心愿单 / 最近笔记）。移动端隐藏日期便签，统计两列。

## 2. 影单 / 书单（`movie.html` / `book.html`）

banner + `.hd-summary` 小结条 → 工具条（类型 / 状态胶囊 + 搜索）→ 卡片网格（桌面 4 列，A 影像默认封面：类型签 + 片名 + 导演·年份压暗角；三态动作）→ 加载更多。数字口径：小结条为互斥分档且与工具条总数自洽（影 87+1+15=103 部；书 13+2+8=23 本）。

## 3. 足迹（`travel.html`）

**单页动线，无模式切换**：banner + 小结条（去过 12 城 / 留下 214 张照片 / 想去 6 处 / 最近 大理）→ 裱框手绘地图（瓦片不手绘，D-45；编号图钉 + 图例 + 指北针 + 地名索引条）+ 旅行时间线 → 地点卡片区（状态 + 搜索在本区工具条；16:10 A 封面 + 照片数角标在右上）。地图 SVG 取色只用 `--hd-*`。

## 4. 笔记（`notes.html` / `note-detail.html` / `note-edit.html`）

- 列表：banner + 小结条（共 36 篇 · 本月 5 · 关联 21 · 最近）→ 草稿便签条 → 搜索 + 标签 → 笔记卡网格。
- 详情（D-46 长文排版）：正文 16.5px / 2.0；h2 手绘下划线；引用红侧笔；代码块方格纸；表格抖线；图片贴胶带（票根示意）；目录桌面右侧 sticky / 移动文首折叠；反链区块收尾「· 完 ·」。
- 编辑：工具条 + 同步态条 + 标题互链提示 + 元信息行 + 左右分栏（移动单栏）；缩略图用 `.hd-fallback.xs`。

## 5. 搜索 / 登录注册（`search.html` / `auth.html`）

- 搜索：hero + 建议词 → 四组结果（`.xs` 封面 + 标题 / 摘要高亮）→ 空态手绘涂鸦。
- 登录 / 注册：独立壳（无前台导航），手账封面左栏 + 暖白表单纸卡；`?mode=register` 注册态。

## 6. 心愿宽版（`plan.html`）

860 单列 → **1120 两栏**（清单 760 + 侧栏 300，gap 44）。左侧四组清单（已过期 / 这周 / 下周及以后 / 还没定日子）结构与动作不变；右侧：本月小结、按类型分布（手绘横条）、下一个日子（日期戳 + `.xs` 封面）、手写批注 + 印章。≤960 侧栏下移，≤720 单列。`.plan-page` 作用域规则并入全局后删除。

## 7. 回顾宽版（`review.html`）

900 单列 → **1120 多栏报告**：报头（年份大字 + 切换 + 归年口径 + 年份胶囊）→ 统计四卡 → 地图（2/3，同足迹画法）+ 评分榜（1/3，影视 / 书籍各前三）→ 标签分布 + 年度笔记并排 → 「· 完 ·」。≤1060 降两栏。

## 8. 验收基准

- 每页三态（亮 / 暗 / 390 移动）与设计图 `_shots/v6`（心愿 / 回顾）及 `_shots/v5`（其余）逐屏比对；
- 正文对比度 ≥ 4.5:1，最小字号 13px；无控制台错误、无横向溢出；
- 心愿页纳入全站令牌后视觉无回归（FR-007-2 验收项）。
