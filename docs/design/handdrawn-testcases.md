## 4. 回归（FR-007-5，任何一页合入前全绿）

- 条目增删改查、状态流转（想 / 在做 / 看过）、完成弹窗（日期 / 评分 / 短评）；
- 筛选与搜索（影 / 书 / 足迹 / 笔记 / 全站搜索至少 2 字约束）；
- 地图（足迹 / 回顾）加载与点选；照片查看与上传；
- 笔记读写：草稿保存 / 恢复、互链与反链、图片搬运（#56 / #68 链路）；
- 主题切换（圆形扩散）与移动端（390 无横向溢出、底部 tab 四项）。
